This page edits the live menu. It is for the shop only — everything else on the site is public.

Forgotten it? On the server, run npm run admin:passwd to set a new one. There is no recovery email, and no default password.

This copy of the site is served as plain files — GitHub Pages, Netlify, Cloudflare Pages or a similar host. There is no Node process here, so there is nothing for the editor to save a menu to. Signing in cannot work on this copy.

Two ways to change the menu:

  1. On this copy: edit assets/data/menu.json, run npm run menu, then commit and push. npm run check validates it.
  2. With this editor: run npm start on a Node host (a laptop, a small VPS, Render, Railway, Fly.io) and open /admin there.

Everything else on the site works here: the menu, the order builder and the WhatsApp hand-off are all static.

The menu

Every change saves straight away and rebuilds menu.html — there is no draft state to forget about. The two rules the site has always followed still apply: a price has to be printed on the board in the shop, and a photograph has to be of the actual dish.

Prices printed on the board

A dish may only use one of these. If the shop raises a price, you have to photograph the new board — then add the number here. This is what stops a slipped digit becoming a real price on the site.

How this works

  • Add — “Add a dish” in a section. The board number must be free.
  • Edit — change the row and save. The public page updates immediately.
  • Delete — removes the dish from the site and from menu.json.
  • Photo — upload a JPEG, PNG or WebP. It is re-encoded, resized and stripped of metadata, and the same file is offered at three sizes.
  • Order — the arrows move a dish up or down within its section.

If something goes wrong, the previous version is in git: git log assets/data/menu.json.
